# QALIM website

- Keep changes simple, fast and efficient. Reuse the static HTML, CSS and JavaScript stack.
- Keep this repository separate from the game at qalim-ticktack.
- Design for phones first, then tablets and desktop. Keep touch targets at least 44px.
- Use QALIM's forest green, cream and lime branding. Keep privacy and removal steps easy to find.
- Do not claim store availability, ratings, user counts or safety features that have not been verified.
- Never expose SMTP credentials or send submitted data to an address supplied by the visitor.
- Do not claim a request was sent unless the mail server accepted it. Preserve form values on failure.
- Keep privacy disclosures consistent with the game and avoid requesting unnecessary personal data.
- Run the build, mail-handler tests and a phone-sized browser check before publishing changes.
